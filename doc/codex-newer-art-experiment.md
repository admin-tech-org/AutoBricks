## 本次真正需要判斷的地方

1. 平板某個區塊是橫排，桌機和手機卻都直排。原生設定是否固定，必須把中間斷點一起考慮。
2. 直接把 computed line-height 的絕對 px 寫到含較大 span 的標題，會破壞原站的相對行高繼承。
3. 原站直接內嵌的三個 SVG 需要輸出成原生 SVG 元件；當一般 div 轉換會遺失箭頭。
4. Bricks 1.12.5 的影片 controls 使用 `isset` 判斷，寫 false 仍會出現控制列；應省略該設定。
5. Bricks 會掃描自訂 CSS 的字型名稱而自動載入 Google Fonts；本機字型改用本站別名，避免重複下載。首屏影片另關閉該元素的延遲載入。
6. 輪播在斷點變更、字型載入之間可能短暫保留舊尺寸。量測前等待版面穩定並更新輪播，避免把暫態誤判為 RWD 缺陷。

這些細節留在站別紀錄。主要 skill 不必逐条加入，仍以完整內容、可編輯產物、RWD、互動與正式匯入後的素材身分作為交付標準。
